# Báo cáo chung

N4 phụ trách biên tập BaoCao_Nhom.docx từ các phần đã được kiểm tra trong docs/. Hải kiểm tra nội dung và bản cuối trước khi nộp.

Quy trình: nhận phần viết của từng người → thống nhất thuật ngữ → ghép nội dung và hình ER → kiểm tra → xuất BaoCao_Nhom.pdf nếu cần nộp PDF.

Chỉ người được giao tổng hợp sửa file Word chung. Các thành viên sửa phần riêng trong docs/ và gửi Pull Request. Git không tự ghép nội dung nhiều file Word thành một báo cáo.

Giữ một tên file ổn định; lịch sử Git đã lưu phiên bản nên tránh các tên như final_final_2.docx.
