# Sơ đồ ER

Mỗi người lưu sơ đồ Draw.io theo phần việc, ví dụ lich-chieu.drawio, ve-khach-hang.drawio. Có thể xuất thêm PDF/PNG cùng tên để cả nhóm xem nhanh; luôn giữ bản .drawio để chỉnh sửa.

Hải phụ trách file ER_Tong.drawio sau khi nhận các phần. Trước khi ghép, thống nhất thực thể dùng chung, tên thuộc tính, khóa và lực lượng tham gia.

Giải thích chi tiết lưu trong docs/, chỉ ghi chú ngắn cần thiết trên sơ đồ. Không để nhiều người sửa cùng file .drawio một lúc.
