# Tài liệu từng phần

Mỗi người viết phần mình phụ trách, lưu file theo tên nhánh: lich-chieu.docx, ve-khach-hang.docx, nhan-su.docx, van-hanh-doi-tac.docx, marketing-tong-hop.docx. Có thể dùng .md nếu nhóm thống nhất.

Nội dung giai đoạn đầu:
1. YC1: mô tả nghiệp vụ, đối tượng, quy trình và quy tắc cần quản lý.
2. YC2: giải thích cách xác định thực thể, thuộc tính, khóa, liên kết và lực lượng tham gia; nêu lý do lựa chọn.
3. Ghi các giả định và điểm cần thống nhất với phần khác.

Sơ đồ gốc lưu ở er/. N4 dùng phần viết của từng người để tổng hợp báo cáo chung.
